关于 Morroa

一个关注 Web 技术、开源与产品设计的独立博客。

你好，我是 Morroa。

这里主要记录我在开发、产品和写作过程中的思考。相比追逐热点，我更愿意写下那些经过时间检验、真正有用的东西。

我会写些什么#

  • Web 开发与工程实践
  • 开源工具和效率方法
  • 产品设计与内容创作
  • 偶尔的阅读与生活记录

关于这个博客#

这个博客基于 Next.js、TypeScript 和 Tailwind CSS 构建。文章内容全部使用 Markdown 管理，并可以一键静态导出到 GitHub Pages 或 Vercel。

如果你有任何想法，欢迎通过邮件或 GitHub 联系我。
